Método de Ensemble

DiabPredict utiliza un enfoque de ensemble que combina las predicciones de los tres modelos para obtener un resultado más robusto y preciso.

¿Cómo funciona?
  1. Cada modelo analiza tus datos de forma independiente
  2. Cada modelo genera su propia probabilidad de riesgo
  3. Se calcula el promedio de las tres probabilidades
  4. El resultado final es más confiable que usar un solo modelo
Ventaja del Ensemble

Al combinar múltiples modelos, reducimos el riesgo de errores individuales y aprovechamos las fortalezas de cada algoritmo.

Métricas de Rendimiento

Los modelos fueron entrenados y evaluados con el dataset Pima Indians Diabetes, dividido en conjuntos de entrenamiento (70%), validación (15%) y prueba (15%).

Explicación de Métricas:
  • Accuracy (Precisión): Porcentaje de predicciones correctas totales
  • Precision (Exactitud): De los casos predichos como positivos, cuántos realmente lo son
  • Recall (Sensibilidad): De todos los casos positivos reales, cuántos fueron detectados
  • F1-Score: Media armónica entre Precision y Recall

Detalles Técnicos

Preprocesamiento de Datos:
  • Tratamiento de valores faltantes (codificados como 0) mediante imputación con mediana
  • Normalización de características usando StandardScaler
  • División estratificada para mantener proporción de clases
Optimización de Hiperparámetros:
  • GridSearchCV con validación cruzada de 5 folds
  • Búsqueda exhaustiva en espacio de hiperparámetros
  • Selección basada en accuracy en conjunto de validación
Tecnologías Utilizadas:
  • Python 3.13 - Lenguaje de programación
  • scikit-learn 1.8.0 - Biblioteca de Machine Learning
  • pandas 2.3.3 - Manipulación de datos
  • numpy 2.3.5 - Cálculos numéricos
  • Flask 3.0.0 - Framework web
Limitaciones Importantes
  • Los modelos fueron entrenados con datos de mujeres de la tribu Pima Indians, por lo que pueden tener menor precisión en otras poblaciones
  • La precisión del 75-76% significa que aproximadamente 1 de cada 4 predicciones puede ser incorrecta
  • Los modelos no consideran todos los factores de riesgo posibles para diabetes
  • Este sistema NO reemplaza el diagnóstico médico profesional
